# У вас несколько видов API, в чем их ключевые отличия?

> Источник: https://support.travelpayouts.com/hc/ru/articles/206635237 (обновлено 2023-08-11, сохранено 2026-09-27)

Здесь представлены отличия между API (доступ к данным, поиск билетов и отелей в реальном времени).  

[API доступа к данным](https://support.travelpayouts.com/hc/ru/articles/203956163) (открыты сразу после регистрации) предоставляет партнёрам доступ к нашему кэшу, в котором хранится история запросов всех пользователей за последние 48 часов.

[Поиск авиабилетов в реальном времени](https://support.travelpayouts.com/hc/ru/articles/203956173) и [поиск отелей](https://support.travelpayouts.com/hc/ru/articles/203956133) позволяют партнёрам получать актуальные данные от агентств и авиакомпаний через наш сервер.
