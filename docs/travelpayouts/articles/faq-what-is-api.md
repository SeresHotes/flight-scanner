# Что такое API и зачем оно нужно?

> Источник: https://support.travelpayouts.com/hc/ru/articles/206635207 (обновлено 2025-10-22, сохранено 2026-09-27)

В статье представлен ответ на самый главный вопрос об API Авиасейлс — «Зачем оно нужно?»                     

Что такое API и зачем оно нужно?

API [Aviasales](https://support.travelpayouts.com/hc/ru/sections/201008338) позволяет отправлять запросы к нашему серверу и получать в ответ полезные данные о билетах. Партнёры могут получать:

- данные о самых дешевых билетах по выбранному направлению;
- информацию об аэропортах и авиакомпаниях;
- список самых популярных направлений перелёта из выбранного города;
- подборку спецпредложений авиакомпаний и многое другое.
