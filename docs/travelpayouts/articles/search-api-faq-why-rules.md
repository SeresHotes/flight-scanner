# Почему правила поискового API такие?

> Источник: https://support.travelpayouts.com/hc/ru/articles/115007743388 (обновлено 2026-08-12, сохранено 2026-09-27)

Узнайте из предоставленной статьи, чем именно аргументированы правила нашего поискового API.        

Согласно [условиям](https://support.travelpayouts.com/hc/ru/articles/210995808-%D0%A3%D1%81%D0%BB%D0%BE%D0%B2%D0%B8%D1%8F-%D0%BF%D1%80%D0%B5%D0%B4%D0%BE%D1%81%D1%82%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0-%D0%BA-API-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA%D0%B0-%D0%B1%D0%B8%D0%BB%D0%B5%D1%82%D0%BE%D0%B2), мы запрещаем отправку автоматических запросов в API поиска с целью получить цены. Это связано с определенными правилами: агентства оплачивают сбор за каждый запрос в GDS (Global Distribution System). GDS — это глобальная система, которая позволяет агентствам находить и бронировать авиабилеты.

Так что большое количество запросов без заказов будут стоить им дорого. Они обратятся к нам, чтобы узнать, почему нет заказов при таком большом количестве запросов. И мы будем вынуждены заблокировать доступ к API. Ведь и мы, и партнёры, получаем комиссионные от агентств — соответственно, нам нужно соблюдать их правила.
