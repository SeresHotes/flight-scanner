# Где найти API-ключ (токен)

> Источник: https://support.travelpayouts.com/hc/ru/articles/13024069738386 (обновлено 2026-09-23, сохранено 2026-09-27)

При работе с инструментами Travelpayouts — такими как API партнёрских программ, White Label или WordPress плагин — необходим **API ключ**.

Это ваш уникальный идентификатор, который позволяет системе понять, что вы — авторизованный партнёр. Ключ выдается после регистрации на платформе.

Чтобы найти свой API-ключ в личном кабинете, выполните следующие действия:

1.  Войдите в свою учётную запись [Travelpayouts](https://app.travelpayouts.com/).
2.  Перейдите в раздел **Профиль**:\
    \
    ![](https://support.travelpayouts.com/hc/article_attachments/25925572591634)\
     
3.  Перейдите на вкладку API-ключ:

![](https://support.travelpayouts.com/hc/article_attachments/33566216730514)

Здесь вы увидите ваш текущий ключ. Его можно:

- **Скопировать** — чтобы вставить в нужный инструмент или настройку.
- **Обновить,** нажав кнопку **Обновить ключ**.

#### Важно при обновлении ключа

Если вы обновите ключ, **старый немедленно станет недействительным**. Это означает, что все инструменты и интеграции, где он использовался, перестанут работать.

Чтобы восстановить их работу, замените старый ключ на новый в настройках всех ваших интеграций.
