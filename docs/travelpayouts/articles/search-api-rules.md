# Правила использования API поиска

> Источник: https://support.travelpayouts.com/hc/ru/articles/34788165535250 (обновлено 2026-06-30, сохранено 2026-09-27)

Технические и продуктовые требования к использованию Search API после получения доступа.                                                                                            

Если **вы уже получили доступ к API Поиска**, убедитесь, что ваша интеграция соответствует правилам ниже. Эти требования обязательны — они помогают обеспечить корректную работу инструментов и честное использование API.

### Поиск только по действию пользователя

- Каждый поисковый запрос должен быть инициирован пользователем.
- Результаты поиска должны отображаться пользователю в полном объёме.

### Логика бронирования

- Рядом с каждым вариантом перелёта должна быть кнопка **«Купить»**.
- Ссылка на сайт агентства должна генерироваться **только после нажатия пользователем на кнопку «Купить»**.
- Автоматическая генерация или предзагрузка ссылок запрещена.

### Ограничения на использование данных

Запрещено:

- автоматически собирать или парсить данные из поисковой выдачи с помощью API;
- использовать Search API совместно с API других метапоисковиков авиабилетов.

### Технические требования

- Запросы к API должны выполняться **с сервера**. Клиентские (Ajax) запросы не поддерживаются.
- Запросы с localhost IP-адресов (127.0.0.1–127.255.255.255) запрещены.

### Требования к показателям конверсии

- Конверсия из поиска в клик по кнопке «Купить» должна быть не ниже 9%. 
- Конверсия из клика по кнопке «Купить» в бронирование — не ниже 5%.

### Ограничения для SEO

Страница с найденными авиабилетами должна быть закрыта для поисковых ботов в robots.txt. Например, если билеты выводятся на странице *www.sitename.com/search*, то robots.txt должен содержать строки:

```
User-Agent: *
Disallow: /search/
```

### Важно

Нарушение этих правил может привести к **отключению доступа к API**.
