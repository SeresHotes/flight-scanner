# Какие имеются ограничения на запросы к API?

> Источник: https://support.travelpayouts.com/hc/ru/articles/205895848 (обновлено 2023-08-11, сохранено 2026-09-27)

Узнайте, сколько запросов в час может отправлять один партнёр с одного IP-адреса при работе с API.  

По умолчанию один партнёр может отправлять не более 200 запросов в час с одного IP-адреса при работе с API поиска билетов Авиасейлс. При необходимости это ограничение может быть изменено.

Для API Авиаселйс доступа к данным и статистики Travelpayouts существуют пятиминутные и часовые лимиты. Подробнее о них написано в статье [Лимиты при работе с API](https://support.travelpayouts.com/hc/ru/articles/4402565416594).

При работе с API данных рекомендуется кэшировать результаты на своей стороне на 24 часа, это уменьшит количество запросов к нашим серверам и увеличит скорость загрузки страниц сайта партнёра.
