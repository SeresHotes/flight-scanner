# Существуют ли требования к сайтам для использования на них API?

> Источник: https://support.travelpayouts.com/hc/ru/articles/205895858 (обновлено 2026-08-30, сохранено 2026-09-27)

Какие требования нужно соблюдать, чтобы получить доступ к API поиска авиабилетов и отелей.                                    

Для использования API доступа к данным требуется соблюдать [партнёрское соглашение](https://support.travelpayouts.com/hc/ru/articles/203956053). Чтобы получить доступ к API поиска авиабилетов и отелей, необходимо соблюдение следующих требований:

1.  Каждый поисковый запрос должен быть инициирован пользователем, результат запроса должен быть показан пользователю в полном объёме. В результатах каждого запроса должна быть кнопка «купить» рядом с каждым вариантом перелёта.

2.  Ссылка для перехода на сайт агентства может быть сгенерирована ТОЛЬКО после нажатия на кнопку «Купить» пользователем. Автоматическая генерация данной ссылки запрещена. Нарушение этого правила приведёт к отключению поиска API для партнера.

3.  Запрещено использовать наш API поиска вместе с API других метапоисковиков авиабилетов.

4.  Запрещено отправлять запросы с localhost IP-адресами (127.0.0.1-127.255.255.255).

5.  Запрещено с помощью API поиска автоматически собирать данные из поисковой выдачи.

6.  Страница с найденными авиабилетами должна быть закрыта для поисковых ботов в robots.txt. Например, если билеты выводятся на странице *www.sitename.com/search*, то robots.txt должен содержать строки:

    ``` hljs
    User-Agent: *
    Disallow: /search/
    ```

7.  Коэффициент конверсии поисков в клики по кнопке «Купить» не должен быть ниже 9%. Конверсия кликнувших «Купить» в покупателей — не ниже 5%.

8.  Необходимо предоставить прототипы/дизайны будущего проекта или существующий проект, где планируется использовать функцию поиска авиабилетов, описание самого проекта и того, как будет использоваться наш API.

9.  В письме с запросом доступа укажите, почему не подходят стандартные методы интеграции (поисковые формы, White Label, API доступа к данным)?

**Обратите внимание!** **Ajax-запросы к API не работают**, так как в открытом виде передаётся ключ доступа. Необходимо делать запросы к API с сервера, на клиенте сделать это не получится.

\* — не принимается во внимание для проектов в рамках акций и партнёрских марафонов.
