# Условия предоставления доступа к API данных от Aviasales

> Источник: https://support.travelpayouts.com/hc/ru/articles/203956083 (обновлено 2026-08-28, сохранено 2026-09-27)

Узнайте из представленной статьи, когда стоит использовать API данных и что для этого нужно.                                                                                

## API доступа к данным

API-доступ к данным отдаёт цены из кэша на основе истории поисков пользователя. Диапазон хранения составляет от 2 до 7 дней в зависимости от типа запроса.

Рекомендуем использовать этот API для информирования пользователей и для генерации контентных страниц на сайте.

**Доступ предоставляется всем партнёрам сразу после регистрации в** [Travelpayouts](https://www.travelpayouts.com/) подключения к программе [Aviasales](https://app.travelpayouts.com/programs/100/about).

Для работы с API необходимо использовать ключ. Ваш уникальный API ключ находится в разделе [Профиль](https://app.travelpayouts.com/profile/info) на вкладке API ключ.

Документация находится [здесь](https://support.travelpayouts.com/hc/ru/articles/203956163).
