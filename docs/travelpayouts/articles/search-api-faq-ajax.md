# Почему не работает запрос на ajax в API поиска авиабилетов

> Источник: https://support.travelpayouts.com/hc/ru/articles/216092357 (обновлено 2026-09-14, сохранено 2026-09-27)

Ознакомьтесь в данной статье с причиной неработающего ajax-запроса к API поиска авиабилетов.                                                                                          

Ajax-запросы к [API поиска авиабилетов](https://support.travelpayouts.com/hc/ru/articles/203956173-API-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA%D0%B0-%D0%B0%D0%B2%D0%B8%D0%B0%D0%B1%D0%B8%D0%BB%D0%B5%D1%82%D0%BE%D0%B2-%D1%81%D0%BB%D0%BE%D0%B6%D0%BD%D1%8B%D0%B5-%D0%BC%D0%B0%D1%80%D1%88%D1%80%D1%83%D1%82%D1%8B-%D0%B8-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA-%D0%B2-%D1%80%D0%B5%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%BC-%D0%B2%D1%80%D0%B5%D0%BC%D0%B5%D0%BD%D0%B8) не работают, так как в них в открытом виде передаётся партнёрский ключ (токен) доступа. А это очень плохо с точки зрения безопасности.

Запросы к API необходимо отправлять с сервера, на клиенте это сделать не получится.
