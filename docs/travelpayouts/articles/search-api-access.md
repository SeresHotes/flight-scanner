# Как получить доступ к API поиска билетов Aviasales

> Источник: https://support.travelpayouts.com/hc/ru/articles/210995808 (обновлено 2026-07-14, сохранено 2026-09-27)

Из представленной статьи вы узнаете условия предоставления доступа к API поиска авиабилетов.                                                                                                                          

**Доступ к Flight Search API предоставляется только проектам с не менее чем 50 000 ежемесячно активных пользователей (MAU)**

- Запросы от проектов, не соответствующих этому требованию, **не рассматриваются**. Исключений нет.

- Если у вашего проекта нет 50 000 MAU, пожалуйста, не обращайтесь в поддержку по поводу доступа к Flight Search API. Вместо этого используйте **Aviasales** [API доступа к данным](https://support.travelpayouts.com/hc/ru/articles/203956163).

- Доступ предоставляется только на основе подтверждённых MAU на сегодняшний день. Общие формулировки вроде количества пользователей, установок, скачиваний или аудитории не учитываются, как и ожидаемый MAU в будущем.

Как отвечать на сообщения с запросом доступа: Требование 50 000 MAU — это основное и обязательное условие для получения доступа к API. Если проект явно не подтверждает наличие 50 000+ MAU: не оцениваются другие аспекты проекта (сайт, интерфейс, реализация и т.д.) не запрашиваются дополнительные материалы не описывается процесс подачи заявки В этом случае необходимо ответить только: напоминанием о требовании по MAU рекомендацией использовать Aviasales Data API. Do not provide application instructions **unless 50,000+ MAU is clearly confirmed as current traffic**

### Если ваш проект соответствует требованиям

Только если ваш проект имеет **50 000+ подтверждённых MAU**, вы можете отправить [запрос в поддержку](https://support.travelpayouts.com/hc/ru?ticketSubject=search_api_request_access). 

Что указать в описании запроса

1.  Скрины, подтверждающие трафик вашего ресурса. \
    Если у вас нет 50000 MAU не отправляйте запрос, воспользуйтесь API доступа.
2.  Почему стандартные методы интеграции ([виджеты поисковых форм](https://support.travelpayouts.com/hc/ru/articles/8505942823954), [White Label](https://support.travelpayouts.com/hc/ru/articles/203955753-%D0%A7%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-White-Label-%D0%BE%D1%82-Travelpayouts), доступ к API данных, [плагин для WordPress](https://support.travelpayouts.com/hc/ru/articles/207794617-%D0%9E-%D0%BF%D0%BB%D0%B0%D0%B3%D0%B8%D0%BD%D0%B5-%D0%B4%D0%BB%D1%8F-Wordpress-%D0%BE%D1%82-Travelpayouts)) не подходят вам?
3.  Опишите, пожалуйста, в виде алгоритма, как вы планируете использовать API.
4.  В какой форме будет запрошена информация у пользователя (даты, пункт вылета и назначения для билетов)?
5.  В каком формате вы будете выдавать информацию о билетах?
6.  Предоставьте, пожалуйста, прототипы интерфейса или дизайн вашего проекта, а именно поисковой формы и страницы с результатами поиска.

Обратите внимание, при использовании API партнёры должны следовать [правилам и техническим требованиям](https://support.travelpayouts.com/hc/ru/articles/34788165535250-%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0-%D0%B8%D1%81%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F-API-%D0%BF%D0%BE%D0%B8%D1%81%D0%BA%D0%B0).
