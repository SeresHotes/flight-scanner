# Где брать названия валют

> Источник: https://support.travelpayouts.com/hc/ru/articles/360020759251 (обновлено 2024-04-04, сохранено 2026-09-27)

Узнайте, как получить названия валют, если вы используете API данных от Авиасейлс.                  

Если вы используете наше [API данных](https://support.travelpayouts.com/hc/ru/articles/203956163) и вам требуется выводить не только код валюты, но и её название, вы можете использовать бесплатные данные из [Unicode Common Locale Data репозитория](https://github.com/unicode-cldr):

- английский язык: [https://github.com/unicode-cldr/cldr-numbers-modern/blob/master/main/en/currencies.json](https://github.com/unicode-cldr/cldr-numbers-modern/blob/master/main/en/currencies.json)
- русский язык: [https://github.com/unicode-cldr/cldr-numbers-modern/blob/master/main/ru/currencies.json](https://github.com/unicode-cldr/cldr-numbers-modern/blob/master/main/ru/currencies.json)
