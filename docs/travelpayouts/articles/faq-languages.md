# Какие языки поддерживаются в API поиска авиабилетов и отелей?

> Источник: https://support.travelpayouts.com/hc/ru/articles/205895888 (обновлено 2026-06-23, сохранено 2026-09-27)

Узнайте, на каком языке вы можете создать сайт или мобильное приложение с помощью нашего API поиска.

Наш API поиска билетов поддерживает следующие языки:

- русский;
- английский;
- французский;
- испанский;
- немецкий;
- итальянский.

Это означает, что вы можете создать сайт или мобильное приложение для любой страны, говорящей на одном из этих языков.
