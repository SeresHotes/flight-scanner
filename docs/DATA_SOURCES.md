# Источники данных о ценах

Решение по источникам для планировщика маршрутов (мультирегиональные поездки
вида `MOW/EVN → ANY → SEOUL → ANY → MOW/EVN`, где один из ANY в Китае).

## Принцип

Планировщик работает **query-time**: цены запрашиваются под конкретный маршрут
пользователя, on-the-fly, с кэшированием по спросу. Мы **не** собираем цены всего
мира заранее (bulk) — это невозможно/забанят/против affiliate-модели.

Единого источника, сшивающего Москву + Сеул + Китай, не существует **by design**
(геополитическая + коммерческая фрагментация). Поэтому каждое плечо маршрута
роутится к своему источнику.

## Источники по плечам маршрута

| Плечо | Источник | Статус |
|---|---|---|
| `MOW → *` / `* → MOW` | **Aviasales Data API** (Travelpayouts) | ✅ подключён (`TRAVELPAYOUTS_TOKEN`) |
| `EVN → *` / `* → EVN` | Aviasales + Duffel | Aviasales есть; Duffel — TODO |
| `* → SEOUL` / хабы вне РФ/КНР | **Duffel** | ⛔ TODO — обязательно завести |
| китайский стоп (в/из) | **Trip.com** (через тот же Travelpayouts) | доступен под текущим токеном, не используется |
| справочники город/аэропорт/страна | Travelpayouts static data files | бесплатно, под текущим токеном |

## ⛔ TODO (обязательно): завести Duffel

**Duffel обязательно должен быть заведён** — без него не покрываются международные
плечи вне РФ и КНР (Сеул, транзитные хабы) и лоукостеры через NDC, которых нет в
GDS-кэшах.

- Sandbox бесплатный (тестовые данные Duffel Airways, нереалистичные цены) —
  годится для разработки интеграции.
- Реальные цены — прод-аккаунт; плата у Duffel на этапе бронирования, не за поиск.
- Отложено сознательно: сейчас работаем с тем, что уже есть (Travelpayouts).

## Что НЕ используем (и почему)

- **Amadeus** — Self-Service закрыт 17.07.2026; Enterprise дорого + сертификация.
- **Kiwi Tequila/Nomad** — invite-only / MAU 50k, и **Москвы там нет** (западная
  инфраструктура делистнула РФ). Кандидат «на потом», если дорастём до порога.
- **Skyscanner API** — только для established-компаний по заявке; РФ делистнута.
- **Западные метапоиски (Kayak/Google Flights/Momondo)** — РФ-плечи не отдают.

## Заметки про текущий Travelpayouts (недоиспользуется)

Под уже имеющимся `TRAVELPAYOUTS_TOKEN` доступно больше, чем мы дёргаем сейчас
(`aviasales/v3/prices_for_dates`):

- `grouped_prices` — цены на все направления из города разом.
- **Trip.com** affiliate — китайское плечо, без новой регистрации.
- static data files (`countries.json` / `cities.json` / `airports.json`) — для
  резолвинга город↔аэропорт и фильтра «стоп в стране X».

Live realtime (Flights Search API) — **gated: MAU 50k + заявка**, сейчас недоступен.
Data API отдаёт реальные цены из пользовательских поисков с лагом до 7 дней;
актуальная цена «на сейчас» — на affiliate-редиректе (кнопка → сайт продавца).

## План: выйти на 50k MAU

Целевой рубеж продукта — **50 000 MAU**. Это разблокирует доступ к
**Flights Search API** (live realtime-цены), который сейчас закрыт порогом
MAU 50k + заявка. До достижения порога работаем на Data API (кэш реальных
поисков, лаг до 7 дней) + affiliate-редиректы на живую цену.

Что даёт достижение 50k MAU:
- live realtime поиск вместо кэша (свежие цены, все рейсы на дату);
- потенциально снятие части rate-limit ограничений (по заявке в support).
