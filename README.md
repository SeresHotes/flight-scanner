# Flight Scanner V2 ✈️

Инструмент для поиска дешевых билетов с пребыванием в промежуточных городах. Скрипт собирает данные о прямых перелетах из города отправления в промежуточные города, а затем из промежуточных городов в конечный пункт назначения.

## 🎯 Возможности

- **🌟 Автоматический поиск**: API автоматически находит все доступные направления (до 1000 маршрутов)
- **Гибкий поиск маршрутов**: поддержка нескольких промежуточных городов или автопоиск
- **Прямые и непрямые перелеты**: поддержка как прямых рейсов, так и рейсов с пересадками
- **Диапазоны дат**: гибкая настройка дат для каждого этапа
- **Анализ комбинаций**: автоматический подбор оптимальных вариантов
- **🚌 Переходы между аэропортами** (включено по умолчанию):
  - Поиск с учетом близких аэропортов (например, прилет в SVO, вылет из DME)
  - Фильтрация по странам (по умолчанию только внутри одной страны)
  - Показ расстояний между аэропортами
- **Статистика**: детальная информация по ценам и городам

## 📋 Требования

- Python 3.9+
- Poetry (менеджер зависимостей)
- API токен от [Travelpayouts](https://www.travelpayouts.com/)

## 🚀 Установка

1. Клонируйте репозиторий или скачайте файлы

2. Установите зависимости:
```bash
poetry install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Добавьте ваш API токен в файл `.env`:
```
TRAVELPAYOUTS_TOKEN=ваш_токен_здесь
```

## 📖 Использование

### Шаг 1: Сбор данных

Используйте скрипт `collect_flights.py` для сбора данных о перелетах:

```bash
poetry run python collect_flights.py <ORIGIN> [DESTINATION] \
  --leg1-dates <START_DATE> <END_DATE> \
  --leg2-dates <START_DATE> <END_DATE> \
  [--intermediate <CITY1> [CITY2 ...]]
```

#### Параметры:

- `ORIGIN` - код города отправления (IATA)
- `DESTINATION` - код конечного города (IATA) - **опционально**
- `--leg1-dates` - диапазон дат для первого этапа (формат: YYYY-MM-DD)
- `--leg2-dates` - диапазон дат для второго этапа (формат: YYYY-MM-DD) - **опционально**
- `--intermediate` - список промежуточных городов (IATA коды) - **опционально**
- `--currency` - валюта (по умолчанию RUB)
- `--allow-indirect` - разрешить непрямые перелеты (с пересадками). По умолчанию только прямые рейсы
- `--output` - путь к файлу для сохранения (опционально)

#### Примеры:

**🌟 НОВЫЙ СПОСОБ (рекомендуется) - автоматический поиск всех направлений:**
```bash
# API сам найдёт все доступные направления из Москвы и в Бангкок
poetry run python collect_flights.py MOW BKK \
  --leg1-dates 2026-02-15 2026-02-20 \
  --leg2-dates 2026-02-25 2026-03-05
```

**Старый способ - конкретные промежуточные города:**
```bash
# Москва → Стамбул/Дубай → Бангкок
poetry run python collect_flights.py MOW BKK \
  --leg1-dates 2026-02-15 2026-02-20 \
  --leg2-dates 2026-02-25 2026-03-05 \
  --intermediate IST DXB
```

**Только исходящие рейсы (все направления из города):**
```bash
# Все рейсы из Москвы за указанный период
poetry run python collect_flights.py MOW \
  --leg1-dates 2026-02-15 2026-02-20
```

**С разрешением непрямых перелетов (с пересадками):**
```bash
# Поиск с учетом рейсов с пересадками
poetry run python collect_flights.py MOW BKK \
  --leg1-dates 2026-02-15 2026-02-20 \
  --leg2-dates 2026-02-25 2026-03-05 \
  --allow-indirect
```

### Шаг 2: Анализ данных

Используйте скрипт `aggregate_flights.py` для анализа собранных данных:

```bash
poetry run python aggregate_flights.py <INPUT_FILE> [OPTIONS]
```

#### Параметры:

- `INPUT_FILE` - путь к файлу с собранными данными
- `--min-stay` - минимальная длительность пребывания в днях (по умолчанию 1)
- `--max-stay` - максимальная длительность пребывания в днях (по умолчанию 30)
- `--top` - количество лучших вариантов для отображения (по умолчанию 10)
- `--unique-cities` - показывать только уникальные промежуточные города (самый дешевый вариант для каждого города)
- `--via` - фильтр по конкретному промежуточному городу (IATA код, например IST или DXB)
- `--disable-airport-transfers` - отключить поиск с учетом переходов между близкими аэропортами (по умолчанию переходы включены)
- `--allow-cross-country-transfers` - разрешить переходы между аэропортами разных стран (по умолчанию только внутри одной страны)
- `--airport-distance` - максимальное расстояние между аэропортами для переходов в км (по умолчанию 100)
- `--airport-network` - путь к файлу с сетью аэропортов (по умолчанию data/airport_network.json)
- `--output` - путь к файлу для сохранения результатов (опционально)

#### Примеры:

**Базовый анализ:**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json
```

**С ограничениями на пребывание (3-7 дней):**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --min-stay 3 --max-stay 7
```

**Вывод топ-20 вариантов:**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --top 20
```

**Только уникальные города (по одному самому дешевому варианту на город):**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --unique-cities
```

**Только через определённый город (например, Стамбул):**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --via IST
```

**С сохранением результатов:**
```bash
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --output results/best_combinations.json
```

**Отключение переходов между аэропортами:**
```bash
# По умолчанию переходы между аэропортами включены
# Чтобы их отключить, используйте флаг --disable-airport-transfers
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --disable-airport-transfers
```

**Разрешить переходы между аэропортами разных стран:**
```bash
# По умолчанию разрешены только переходы внутри одной страны (например, SVO → DME в Москве)
# Чтобы разрешить переходы между странами, используйте флаг --allow-cross-country-transfers
poetry run python aggregate_flights.py data/flights_MOW_BKK_20260215_120000.json \
  --allow-cross-country-transfers
```

### Шаг 3: Построение сети аэропортов (опционально)

Для использования функции переходов между аэропортами необходима сеть аэропортов. Она автоматически создается при первом использовании флага `--enable-airport-transfers`, но вы также можете построить её вручную:

```bash
poetry run python build_airport_network.py [OPTIONS]
```

#### Параметры:

- `--max-distance` - максимальное расстояние между аэропортами в км (по умолчанию 100)
- `--output` - путь к выходному файлу (по умолчанию data/airport_network.json)

#### Примеры:

**Построение сети с расстоянием до 100 км:**
```bash
poetry run python build_airport_network.py --max-distance 100
```

**Построение сети с расстоянием до 150 км и сохранением в другой файл:**
```bash
poetry run python build_airport_network.py \
  --max-distance 150 \
  --output data/airport_network_150km.json
```

**Примечание:** Первая загрузка данных может занять несколько минут. Данные кешируются локально для последующего использования.

## 💡 Советы

1. **Автоматический поиск**: используйте новый способ без указания `--intermediate` для автоматического поиска всех направлений (быстрее и эффективнее)
2. **Ручной выбор**: используйте `--intermediate` только если хотите ограничить поиск конкретными городами
3. **Диапазоны дат**: чем шире диапазон, тем больше вариантов, но дольше сбор данных
4. **Rate limiting**: скрипт автоматически добавляет паузы между запросами
5. **Пребывание**: оптимально 3-7 дней для туристических поездок
6. **Limit**: API возвращает до 1000 уникальных маршрутов за один запрос

## 🐛 Troubleshooting

**Ошибка: "TRAVELPAYOUTS_TOKEN не найден"**
- Проверьте, что файл `.env` существует и содержит токен

**Нет найденных рейсов:**
- Проверьте правильность IATA кодов
- Попробуйте расширить диапазон дат
- Убедитесь, что выбранные города имеют прямые рейсы

**Слишком долгий сбор данных:**
- Сократите диапазон дат
- Уменьшите количество промежуточных городов
